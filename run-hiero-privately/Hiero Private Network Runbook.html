1. Overview

The result is a four-node consensus network with its own genesis, its own treasury key and its own ledger ID. A mirror node and network explorer sit beside it. Each node generates its own private keys locally; only public data leaves a node host. Four nodes tolerate one faulty or stopped node: consensus needs more than two thirds of the weight, so three of four nodes keep the network running.

2. Before you start

Roles

The runbook is written for independent operators, so every step says where it runs. One person can play every role.

Node operator (×4)

Runs one consensus node host. Keeps that node's private keys; shares only its public bundle.

Genesis coordinator

Creates the treasury key, assembles the genesis file from the four public bundles and distributes it. Handles public data only, plus the treasury key.

Mirror operator

Runs the mirror node and explorer. Gets read-only access to each node's record streams.

Hosts

Sizing lessons from the validation runs

Hosts with 8 GB of memory are too small for a consensus node; 16 GB with a 4–10 GB Java heap ran reliably. With 30 GB disks, a test network halted after 3.8 days: event-stream files (on by default, about 5 GB per node per day, never deleted) filled the disks. The configure step now turns event streams off. Monitor disk use regardless, and alert at 80%.

3

Generate node keys

Each nodesudo

Each node generates its own keys on its own host:

  • Gossip signing key (RSA-3072): stays in data/keys.
  • gRPC TLS key (RSA-4096): stays in hedera.key.
  • Node admin key (ED25519): written to ~/hiero-share. Move it offline after this step.

The command also writes a public bundle, node<N>.public.json, and records the node id on the host. Run the line for the host you are on:

Node 3sudo ~/hiero-node.sh gen-keys --node-id 2 --nodes 4 --host 10.0.1.13 --out ~/hiero-sharenode3.public.json
Node 4sudo ~/hiero-node.sh gen-keys --node-id 3 --nodes 4 --host 10.0.1.14 --out ~/hiero-sharenode4.public.json

Expected (node 1)

==> Node id 0 of 4  ->  key files named node1, account 0.0.3
==> Generating gossip signing key for node1 (node id 0)
==> Generating gRPC TLS key (hedera.key / hedera.crt)

Send only the .public.json file to the coordinator. The command refuses to run twice on the same host, so a node identity is never overwritten by accident.

Why per-node key generation

The consensus node repository includes a key generator that produces the same keys for the same node id every time. That is convenient for tests and unsafe for a real network. The script uses fresh random keys from OpenSSL instead.

Create the genesis

Coordinatorno sudo

The coordinator can be any Linux machine with openssl and python3, preferably not a node host. First create the treasury key, which controls account 0.0.2 and all initial HBAR.

bash · coordinator
mkdir -p ~/hiero-genesis && cd ~/hiero-genesis
~/hiero-node.sh gen-genesis-key --out .

Expected

==> Genesis treasury key written to ./genesis.key.pem (store offline)
bootstrap.genesisPublicKey (share with all operators): 6f0c…(64 hex characters)
SDK operator private key (DER hex, keep secret):        302e0201…
Protect the treasury key

The DER hex line is the private key in the form SDKs accept. Store it and genesis.key.pem in a password manager or vault, and never paste them into chat, tickets or shared documents. Step 10 needs the DER hex. Share only the public key (genesis.pub.hex).

Collect the four public bundles in ~/hiero-genesis, then build the genesis file:

bash · coordinator
cd ~/hiero-genesis
~/hiero-node.sh build-genesis --nodes 4 genesis-network.json \
  node1.public.json node2.public.json node3.public.json node4.public.json

Expected

genesis-network.json: 4 nodes, ids [0, 1, 2, 3]; tolerates 1 faulty node(s)
==> sha256 (operators must verify): 5c1e…
Distribute genesis-network.json to every operator. Any byte difference prevents genesis.

Send genesis-network.json and genesis.pub.hex to every node and to the mirror host, and publish the SHA-256 through a second channel.

bash · coordinator
for ip in 10.0.1.11 10.0.1.12 10.0.1.13 10.0.1.14 10.0.1.20; do
  ssh ubuntu@$ip 'mkdir -p ~/hiero-genesis'

done

Each operator checks the file before using it:

bash · each node and the mirror
sha256sum ~/hiero-genesis/genesis-network.json   # must equal the coordinator's value
5

Install the node software

Each nodesudo

Downloads the release zip (about 150 MB) and its .sha384 file from builds.hedera.com, verifies the checksum and installs the jars.

bash · each node
sudo ~/hiero-node.sh install v0.76.4

Expected (last lines)

build-v0.76.4.zip: OK
==> Installed v0.76.4: <n> libs
Checksum only

Consensus node releases are published with SHA-384 checksums but no cryptographic signatures. The checksum protects against corrupted downloads, not against a tampered server. Organisations with stricter supply-chain rules should build from the tagged source (hiero-consensus-node, docs/gradle-quickstart.md) and install with LOCAL_BUILD=<path to hedera-node/data>.

6

Configure the nodes

Each nodesudo

This step:

  • fetches the configuration templates (Solo v0.91.0);
  • installs the genesis file;
  • writes the treasury public key, ledger ID and chain ID;
  • turns event streams off;
  • prints fingerprints of the network-wide files.

Use the same values on every node.

bash · each node
sudo ~/hiero-node.sh configure \
  --genesis ~/hiero-genesis/genesis-network.json \
  --genesis-pubkey ~/hiero-genesis/genesis.pub.hex \
  --ledger-id 0x2a --chain-id 1234

Expected

==> Genesis key set in data/config/application.properties (the file the node reads at genesis)
==> Network-wide file fingerprints (must match on every node):
…  settings.txt
…  data/config/genesis-network.json
…  data/config/application.properties
…  data/config/bootstrap.properties
…  data/config/api-permission.properties

Compare the five fingerprints across all four nodes. They must be identical. A single differing byte in these files stops the nodes from reaching agreement at genesis, or creates diverging state.

The genesis key must be in application.properties

Public documentation places bootstrap.genesisPublicKey in bootstrap.properties, but the node reads it only from data/config/application.properties. If it is missing there, the network starts with the public development key and anyone can control the treasury. The script writes it to the right file and checks it. Step 10 confirms it again from outside.

7

Start the network

Each nodesudo

Installs a systemd unit, hiero-node.service, which restarts the node 10 seconds after a crash, and starts it. Start all four nodes within a few minutes of each other: a node waits until more than two thirds of the network is online.

bash · each node
sudo ~/hiero-node.sh service --heap-min 4g --heap-max 10g

Then watch the status until it reads ACTIVE:

bash · each node
watch -n 10 ~/hiero-node.sh status

A node moves through STARTING_UP, then OBSERVING or CHECKING, to ACTIVE. In the validation runs all four nodes reached ACTIVE within about one minute of the fourth node starting.

9

Set up the mirror node

MirrorEach nodesudo

The mirror node verifies each node's record-stream files against the network's address book, loads them into PostgreSQL and serves the APIs and explorer through nginx on port 8080. It pulls the files with rsync over SSH. On the nodes, the mirror's key may only run a read-only copy of the record-stream folder, and only from the mirror's address.

9.1 Prepare the mirror host

bash · mirror
sudo ~/hiero-mirror.sh prepare-host

This installs Docker, Compose and rsync, creates /opt/hiero-mirror and generates a pull key. It then prints the exact command to run on every node:

==> Host ready. On EVERY consensus node, run:

  sudo ~/hiero-node.sh allow-mirror --from 10.0.1.20 --pubkey "ssh-ed25519 AAAA… hiero-mirror@mirror"

9.2 Grant read-only stream access on every node

Run the printed command on each of the four nodes. The nodes must already be running (step 7), because the record-stream folder is created at start.

bash · each node
sudo ~/hiero-node.sh allow-mirror --from 10.0.1.20 --pubkey "ssh-ed25519 AAAA… hiero-mirror@mirror"
==> Mirror key allowed for hiero-streams: read-only rsync of /opt/hgcapp/recordStreams, only from 10.0.1.20

Use the same ledger ID and chain ID as the nodes.

Fault tolerance

One node may be down at a time: the other three keep reaching consensus, and the stopped node catches up when it returns. In validation, a stopped node rejoined about 40 seconds after starting. With two nodes down the network halts until one returns. Restart nodes one at a time and wait for ACTIVE before touching the next.

Monitoring

Neither the node software nor this runbook ships alerting. At a minimum, alert on:

  • platform status other than 2 for more than 5 minutes, on any node;
  • the same round showing different hash mnemonics on different nodes;
  • disk use above 80%;
  • the systemd unit restarting repeatedly.

Hiero publishes Grafana dashboards for the metrics endpoint in the hiero-consensus-node repository, under hedera-node/infrastructure/grafana.

6. Scope and limitations

Validated:

  • Every step on AWS EC2 Ubuntu 24.04 hosts in one account and network, with the operator roles simulated by one team.
  • Genesis with an independent treasury key.
  • Agreement between the nodes.
  • Stopping and restarting a single node.
  • Mirror import, the REST and web3 APIs, and the explorer.

The state command and the event-stream setting were added after the long-running observation described in section 2. They were checked on the test hosts but not yet through a full rebuild.

Not covered by this runbook:

  • Software upgrades: the network freeze procedure.
  • Adding or removing nodes after genesis.
  • Backup and restore.
  • Client TLS with trusted certificates.
  • High availability for the mirror node.
  • Block nodes and the JSON-RPC relay.
  • Host hardening beyond the firewall rules above.

Hiero's public documentation does not yet describe these procedures for independently operated networks.

Appendix A. hiero-node.sh

#
# hiero-node.sh — provision an independent Hiero consensus node on a Linux host.
#
# Mirrors what Solo (github.com/hiero-ledger/solo) does inside k8s, but for plain VMs/bare metal
# where every node is run by a different operator.

#     3. install                         <--   genesis-network.json + genesis pubkey
#     5. configure

# so a normal account gets "Permission denied". Allow root (sudo) or the node user itself.
need_node_writer() {
  [[ $EUID -eq 0 || $(id -un) == "$HEDERA_USER" ]] && return 0
  die "'$1' writes to $HAPI_DIR (owned by $HEDERA_USER). Run it with sudo: sudo $0 $1 ..."
}
# After writing as root: node files go to the node user (it must read its own keys),
# files meant for the operator go back to whoever called sudo.
own_by_hedera() {
  if [[ $EUID -eq 0 ]] && id "$HEDERA_USER" >/dev/null 2>&1; then chown -RH "$HEDERA_USER:$HEDERA_USER" "$@"; fi  # -H: HapiApp2.0 may be a symlink (node-mgmt-tools)
}
own_by_caller() {
  if [[ $EUID -eq 0 && -n ${SUDO_USER:-} ]]; then chown -R "$SUDO_USER:" "$@"; fi
}

# Remembers this host's node id and the network size, so later commands don't need them again.
NODE_ENV_FILE() { echo "$HAPI_DIR/node.env"; }
load_node_env() {
  NODE_ID="" NETWORK_SIZE=""
  if [[ -r "$(NODE_ENV_FILE)" ]]; then
    # shellcheck disable=SC1090
    source "$(NODE_ENV_FILE)"
  fi
}

# Node id 0 -> "node1": the platform's key loader names files node<id+1>.
node_name() { echo "node$(( $1 + 1 ))"; }

# Set key=value in a .properties file, replacing an existing entry or appending.
set_prop() {
  local file=$1 key=$2 value=$3
  touch "$file"
  if grep -qE "^[[:space:]]*${key//./\\.}[[:space:]]*=" "$file"; then
    python3 - "$file" "$key" "$value" <<'PY'
import re, sys
path, key, value = sys.argv[1:4]
pattern = re.compile(r'^\s*' + re.escape(key) + r'\s*=.*$', re.M)
with open(path) as f: text = f.read()
with open(path, 'w') as f: f.write(pattern.sub(f'{key}={value}', text))
PY
  else
    printf '%s=%s\n' "$key" "$value" >> "$file"
  fi
}

cmd_prepare_host() {
  need_root prepare-host
  if ! id "$HEDERA_USER" >/dev/null 2>&1; then
    log "Creating user $HEDERA_USER (uid $HEDERA_UID)"
    useradd -m -d "/home/$HEDERA_USER" -u "$HEDERA_UID" -s /bin/bash "$HEDERA_USER"
  fi
  log "Creating $HAPI_DIR layout"
  mkdir -p "$HAPI_DIR"/{data/{lib,apps,keys,config,saved,upgrade/current},output}
  chown -R "$HEDERA_USER:$HEDERA_USER" "$(dirname "$(dirname "$HAPI_DIR")")"
  chmod 750 "$HAPI_DIR/data"

  # Install missing tools and the JDK. Releases from v0.76 build with JDK 25 (gradle/toolchain-versions.properties).
  local pkgs=() c java_major=0
  for c in openssl python3 curl unzip; do command -v "$c" >/dev/null 2>&1 || pkgs+=("$c"); done
  if command -v java >/dev/null 2>&1; then
    java_major=$(java -version 2>&1 | awk -F'"' '/version/{split($2, v, "."); print v[1]; exit}')
  fi
  (( java_major >= ${JAVA_MAJOR:-25} )) || pkgs+=("openjdk-${JAVA_MAJOR:-25}-jre-headless")
  if (( ${#pkgs[@]} )); then
    command -v apt-get >/dev/null 2>&1 || die "missing: ${pkgs[*]}; install them with your package manager"
    log "Installing: ${pkgs[*]}"
    apt-get update -qq
    DEBIAN_FRONTEND=noninteractive NEEDRESTART_SUSPEND=1 apt-get install -y -qq "${pkgs[@]}" >/dev/null
  fi
  need openssl python3 curl unzip sha384sum java
  log "java: $(java -version 2>&1 | head -1)"
  log "Host ready. Open firewall: gossip ${DEFAULT_GOSSIP_PORT}/tcp from peer IPs; gRPC ${DEFAULT_GRPC_PORT}-$((DEFAULT_GRPC_PORT+1))/tcp for clients; keep 9999 (metrics) internal."
}

# gen-keys --node-id N --nodes TOTAL --host IP|DNS [--gossip-port N] [--grpc-port N] [--weight N]
#          [--account-num N] [--admin-pubkey <hex|file.pub.pem>] [--out DIR]
# (positional form still works: gen-keys <nodeId> <host> --nodes TOTAL)
cmd_gen_keys() {
  need openssl python3
  need_node_writer gen-keys
  local id="" host="" nodes="" positional=()
  local gossip_port=$DEFAULT_GOSSIP_PORT grpc_port=$DEFAULT_GRPC_PORT weight=1
  local account_num="" admin_pub="" out="."
  while [[ $# -gt 0 ]]; do
    case $1 in
      --node-id) id=$2; shift 2 ;;
      --nodes) nodes=$2; shift 2 ;;
      --host) host=$2; shift 2 ;;
      --gossip-port) gossip_port=$2; shift 2 ;;
      --grpc-port) grpc_port=$2; shift 2 ;;
      --weight) weight=$2; shift 2 ;;
      --account-num) account_num=$2; shift 2 ;;
      --admin-pubkey) admin_pub=$2; shift 2 ;;
      --out) out=$2; shift 2 ;;
      -*) die "unknown option $1" ;;
      *) positional+=("$1"); shift ;;
    esac
  done
  [[ -z $id && ${#positional[@]} -ge 1 ]] && id=${positional[0]}
  [[ -z $host && ${#positional[@]} -ge 2 ]] && host=${positional[1]}
  [[ -n $id && -n $host && -n $nodes ]] || \
    die "usage: gen-keys --node-id <0..N-1> --nodes <N> --host <public-ip-or-dns> [options]"
  [[ $id =~ ^[0-9]+$ ]] || die "--node-id must be a non-negative integer"
  [[ $nodes =~ ^[1-9][0-9]*$ ]] || die "--nodes must be a positive integer (total nodes in the network)"
  (( id < nodes )) || die "--node-id $id is out of range: with --nodes $nodes, ids are 0..$((nodes - 1))"
  (( nodes >= 4 )) || warn "$nodes node(s) cannot tolerate a faulty node; use 4 or more for a real network"
  [[ -n $account_num ]] || account_num=$(( 3 + id ))

  load_node_env
  if [[ -n $NODE_ID && $NODE_ID != "$id" ]]; then
    die "this host is already node id $NODE_ID ($(NODE_ENV_FILE)); one node per host"
  fi

  local name; name=$(node_name "$id")
  local keys="$HAPI_DIR/data/keys"
  mkdir -p "$keys" "$out" || die "cannot create $out"
  [[ -w $out ]] || die "cannot write to --out $out as $(id -un); pass a folder you own, e.g. --out ~/hiero-share"
  log "Node id $id of $nodes  ->  key files named $name, account 0.0.$account_num"

  if [[ -e "$keys/s-private-$name.pem" ]]; then
    die "$keys/s-private-$name.pem already exists; refusing to overwrite a node identity"
  fi

  # Gossip signing key: RSA-3072 / SHA-384, self-signed CA (same profile as Solo's KeyManager).
  log "Generating gossip signing key for $name (node id $id)"
  local tmp; tmp=$(mktemp -d)
  openssl req -x509 -newkey rsa:3072 -sha384 -nodes -days 36500 \
    -keyout "$tmp/key.pem" -out "$keys/s-public-$name.pem" -subj "/CN=s-$name" \
    -addext "basicConstraints=critical,CA:TRUE,pathlen:1" \
    -addext "keyUsage=critical,keyCertSign,cRLSign" \
    -addext "extendedKeyUsage=critical,serverAuth,clientAuth" 2>/dev/null
  openssl pkcs8 -topk8 -nocrypt -in "$tmp/key.pem" -out "$keys/s-private-$name.pem"
  rm -rf "$tmp"

  # gRPC TLS key: RSA-4096 / SHA-384, self-signed.
  if [[ ! -e "$HAPI_DIR/hedera.key" ]]; then
    log "Generating gRPC TLS key (hedera.key / hedera.crt)"
    openssl req -x509 -newkey rsa:4096 -sha384 -nodes -days 36500 \
      -keyout "$HAPI_DIR/hedera.key" -out "$HAPI_DIR/hedera.crt" -subj "/CN=$name" 2>/dev/null
  fi
  chmod 600 "$keys/s-private-$name.pem" "$HAPI_DIR/hedera.key"

  # Node admin key (ED25519) — signs future NodeUpdate/NodeDelete for this node.
  if [[ -z "$admin_pub" ]]; then
    log "Generating node admin ED25519 key -> $out/$name-admin.key.pem (keep offline!)"
    openssl genpkey -algorithm ed25519 -out "$out/$name-admin.key.pem"
    chmod 600 "$out/$name-admin.key.pem"
    openssl pkey -in "$out/$name-admin.key.pem" -pubout -out "$out/$name-admin.pub.pem"
    admin_pub="$out/$name-admin.pub.pem"
  fi

  local bundle="$out/$name.public.json"
  python3 - "$id" "$name" "$host" "$gossip_port" "$grpc_port" "$weight" "$account_num" \
    "$keys/s-public-$name.pem" "$HAPI_DIR/hedera.crt" "$admin_pub" > "$bundle" <<'PY'
import base64, hashlib, json, subprocess, sys, unicodedata
(node_id, name, host, gport, rport, weight, acct, sig_pem, tls_pem, admin) = sys.argv[1:11]
der = subprocess.run(['openssl', 'x509', '-in', sig_pem, '-outform', 'DER'],
                     capture_output=True, check=True).stdout
# HAPI Node.grpc_certificate_hash: SHA-384 of the PEM cert text (UTF-8, NFKD).
tls_text = unicodedata.normalize('NFKD', open(tls_pem).read())
grpc_hash = hashlib.sha384(tls_text.encode('utf-8')).digest()
if all(c in '0123456789abcdefABCDEF' for c in admin) and len(admin) == 64:
    admin_raw = bytes.fromhex(admin)
else:
    spki = subprocess.run(['openssl', 'pkey', '-pubin', '-in', admin, '-outform', 'DER'],
                          capture_output=True, check=True).stdout
    admin_raw = spki[-32:]
json.dump({
    'nodeId': int(node_id), 'name': name, 'host': host,
    'gossipPort': int(gport), 'grpcPort': int(rport), 'weight': int(weight),
    'accountNum': int(acct),
    'gossipCaCertificate': base64.b64encode(der).decode(),
    'grpcCertificateHash': base64.b64encode(grpc_hash).decode(),
    'adminKeyEd25519': base64.b64encode(admin_raw).decode(),
}, sys.stdout, indent=2)
print()
PY
  printf 'NODE_ID=%s\nNETWORK_SIZE=%s\n' "$id" "$nodes" > "$(NODE_ENV_FILE)"
  own_by_hedera "$keys" "$HAPI_DIR/hedera.key" "$HAPI_DIR/hedera.crt" "$(NODE_ENV_FILE)"
  local created=("$bundle")
  [[ -f "$out/$name-admin.key.pem" ]] && created+=("$out/$name-admin.key.pem" "$out/$name-admin.pub.pem")
  own_by_caller "${created[@]}"
  log "Saved node id $id / network size $nodes to $(NODE_ENV_FILE)"
  log "Public bundle written: $bundle"
  log "Send ONLY $bundle to the genesis coordinator. Private keys stay on this host."
}

# gen-genesis-key [--out DIR] : ED25519 key for the genesis treasury (0.0.2).
cmd_gen_genesis_key() {
  need openssl
  local out="."
  [[ ${1:-} == --out ]] && out=$2
  mkdir -p "$out"
  [[ -e "$out/genesis.key.pem" ]] && die "$out/genesis.key.pem exists"
  openssl genpkey -algorithm ed25519 -out "$out/genesis.key.pem"
  chmod 600 "$out/genesis.key.pem"
  local pub_hex der_hex
  pub_hex=$(openssl pkey -in "$out/genesis.key.pem" -pubout -outform DER | tail -c 32 | od -An -tx1 | tr -d ' \n')
  der_hex=$(openssl pkey -in "$out/genesis.key.pem" -outform DER | od -An -tx1 | tr -d ' \n')
  echo "$pub_hex" > "$out/genesis.pub.hex"
  own_by_caller "$out/genesis.key.pem" "$out/genesis.pub.hex"
  log "Genesis treasury key written to $out/genesis.key.pem (store offline)"
  echo "bootstrap.genesisPublicKey (share with all operators): $pub_hex"
  echo "SDK operator private key (DER hex, keep secret):        $der_hex"
}

# build-genesis --nodes N <out.json> <bundle.json>...
cmd_build_genesis() {
  need python3
  local nodes="" args=()
  while [[ $# -gt 0 ]]; do
    case $1 in
      --nodes) nodes=$2; shift 2 ;;
      -*) die "unknown option $1" ;;
      *) args+=("$1"); shift ;;
    esac
  done
  [[ -n $nodes && ${#args[@]} -ge 2 ]] || \
    die "usage: build-genesis --nodes <N> <out.json> <node1.public.json> ... (one bundle per node)"
  [[ $nodes =~ ^[1-9][0-9]*$ ]] || die "--nodes must be a positive integer"
  local out=${args[0]}
  python3 - "$nodes" "${args[@]}" <<'PY'
import base64, ipaddress, json, sys
expected, out, paths = int(sys.argv[1]), sys.argv[2], sys.argv[3:]
bundles = sorted((json.load(open(p)) for p in paths), key=lambda b: b['nodeId'])
ids = [b['nodeId'] for b in bundles]
if len(set(ids)) != len(ids):
    sys.exit(f'duplicate node ids: {ids}')
missing = sorted(set(range(expected)) - set(ids))
extra = sorted(set(ids) - set(range(expected)))
if missing or extra:
    sys.exit(f'--nodes {expected} needs bundles for node ids 0..{expected - 1}; '
             f'missing {missing or "none"}, unexpected {extra or "none"}')
for field in ('accountNum', 'gossipCaCertificate'):
    vals = [b[field] for b in bundles]
    if len(set(vals)) != len(vals):
        sys.exit(f'duplicate {field} across bundles')

def endpoint(host, port):
    try:
        ip = ipaddress.IPv4Address(host)
        return {'ipAddressV4': base64.b64encode(ip.packed).decode(), 'port': port}
    except ipaddress.AddressValueError:
        return {'domainName': host, 'port': port}

meta = []
for b in bundles:
    gossip = [endpoint(b['host'], b['gossipPort'])]
    meta.append({
        'rosterEntry': {
            'nodeId': str(b['nodeId']),
            'weight': str(b['weight']),
            'gossipCaCertificate': b['gossipCaCertificate'],
            'gossipEndpoint': gossip,
        },
        'node': {
            'nodeId': str(b['nodeId']),
            'accountId': {'shardNum': '0', 'realmNum': '0', 'accountNum': str(b['accountNum'])},
            'description': b['name'],
            'gossipEndpoint': gossip,
            'serviceEndpoint': [endpoint(b['host'], b['grpcPort']),
                                endpoint(b['host'], b['grpcPort'] + 1)],
            'gossipCaCertificate': b['gossipCaCertificate'],
            'grpcCertificateHash': b['grpcCertificateHash'],
            'weight': str(b['weight']),
            'adminKey': {'ed25519': b['adminKeyEd25519']},
        },
    })
with open(out, 'w') as f:
    json.dump({'nodeMetadata': meta}, f, indent=2)
    f.write('\n')
n = len(bundles)
print(f'{out}: {n} nodes, ids {ids}; tolerates {(n - 1) // 3} faulty node(s)', file=sys.stderr)
if n < 4:
    print('warning: fewer than 4 nodes cannot tolerate any faulty node', file=sys.stderr)
PY
  own_by_caller "$out"
  log "sha256 (operators must verify): $(sha256sum "$out" | cut -d' ' -f1)"
  echo "Distribute $out to every operator. Any byte difference prevents genesis."
}

# install <tag>   e.g. install v0.76.4      (or LOCAL_BUILD=/path/to/hedera-node/data)
cmd_install() {
  need curl unzip sha384sum
  need_node_writer install
  [[ $# -eq 1 ]] || die "usage: install <release-tag e.g. v0.76.4>"
  local tag=$1
  [[ $tag == v* ]] || tag="v$tag"
  local minor; minor=$(cut -d. -f1-2 <<<"$tag")
  local dl="${DOWNLOAD_DIR:-$HOME/hiero-builds}"
  mkdir -p "$dl"
  local zip="build-$tag.zip" sum="build-$tag.sha384"

  if [[ -n "${LOCAL_BUILD:-}" ]]; then
    log "Installing jars from local build $LOCAL_BUILD"
    [[ -f "$LOCAL_BUILD/apps/HederaNode.jar" ]] || die "$LOCAL_BUILD/apps/HederaNode.jar not found (run ./gradlew assemble)"
    rm -f "$HAPI_DIR"/data/lib/*.jar "$HAPI_DIR"/data/apps/*.jar
    cp "$LOCAL_BUILD"/lib/*.jar "$HAPI_DIR/data/lib/"
    cp "$LOCAL_BUILD"/apps/*.jar "$HAPI_DIR/data/apps/"
  else
    log "Downloading $BUILDS_URL/$minor/$zip"
    (cd "$dl" && curl -fL --retry 3 -O "$BUILDS_URL/$minor/$zip" && curl -fL --retry 3 -O "$BUILDS_URL/$minor/$sum")
    log "Verifying SHA-384"
    (cd "$dl" && sha384sum -c "$sum") || die "checksum mismatch for $zip"
    local x; x=$(mktemp -d)
    unzip -q -o "$dl/$zip" -d "$x"
    rm -f "$HAPI_DIR"/data/lib/*.jar "$HAPI_DIR"/data/apps/*.jar
    mkdir -p "$HAPI_DIR"/data/{lib,apps}
    cp -r "$x"/data/lib/* "$HAPI_DIR/data/lib/"
    cp -r "$x"/data/apps/* "$HAPI_DIR/data/apps/"
    for f in VERSION immediate.sh; do [[ -f "$x/$f" ]] && cp "$x/$f" "$HAPI_DIR/"; done
    [[ -f "$x/during-freeze.sh" ]] && cp "$x/during-freeze.sh" "$HAPI_DIR/during_freeze.sh"
    rm -rf "$x"
  fi
  [[ -f "$HAPI_DIR/data/apps/HederaNode.jar" ]] || die "HederaNode.jar missing after install"
  own_by_hedera "$HAPI_DIR"
  log "Installed $tag: $(ls "$HAPI_DIR"/data/lib/*.jar | wc -l) libs"
}

# configure --genesis FILE --genesis-pubkey HEX [--ledger-id 0x..] [--chain-id N]
#           [--grpc-port N] [--templates DIR|URL]
cmd_configure() {
  need python3 curl sha256sum
  need_node_writer configure
  local genesis="" genesis_pub="" ledger_id="" chain_id="" grpc_port="" templates="$TEMPLATES_URL" event_streams=0
  while [[ $# -gt 0 ]]; do
    case $1 in
      --keep-event-streams) event_streams=1; shift ;;
      --genesis) genesis=$2; shift 2 ;;
      --genesis-pubkey) genesis_pub=$2; shift 2 ;;
      --ledger-id) ledger_id=$2; shift 2 ;;
      --chain-id) chain_id=$2; shift 2 ;;
      --grpc-port) grpc_port=$2; shift 2 ;;
      --templates) templates=$2; shift 2 ;;
      *) die "unknown option $1" ;;
    esac
  done
  [[ -f "$genesis" ]] || die "--genesis <genesis-network.json> is required"
  [[ -f "$genesis_pub" ]] && genesis_pub=$(tr -d ' \n' < "$genesis_pub")
  [[ $genesis_pub =~ ^[0-9a-fA-F]{64}$ ]] || die "--genesis-pubkey must be a 64-hex-char ED25519 public key (from gen-genesis-key)"
  [[ $genesis_pub == 0aa8e21064c61eab86e2a9c164565b4e7a9a4146106e0a6cd03a8c395a110e92 ]] && \
    die "that is the public well-known dev genesis key; generate your own with gen-genesis-key"

  local cfg="$HAPI_DIR/data/config"
  mkdir -p "$cfg"
  log "Fetching config templates from $templates"
  local f
  for f in settings.txt log4j2.xml application.properties bootstrap.properties api-permission.properties; do
    local dest="$cfg/$f"
    [[ $f == settings.txt || $f == log4j2.xml ]] && dest="$HAPI_DIR/$f"
    if [[ -d $templates ]]; then cp "$templates/$f" "$dest"; else curl -fsSL "$templates/$f" -o "$dest"; fi
  done

  # Event streams (event.enableEventStreaming, default true) write a file every 5 s to /opt/hgcapp/eventsStreams
  # and nothing deletes them: ~5 GB/day per node on an idle network, which filled 30 GB disks in 3.8 days and
  # halted a test network. Mirror nodes use record streams, not event streams. Off unless --keep-event-streams.
  sed -i '/^[[:space:]]*event\.enableEventStreaming[[:space:]]*,/d' "$HAPI_DIR/settings.txt"
  (( event_streams )) || printf 'event.enableEventStreaming, false\n' >> "$HAPI_DIR/settings.txt"

  cp "$genesis" "$cfg/genesis-network.json"
  # The node's bootstrap config (BootstrapConfigProviderImpl) reads ONLY data/config/application.properties,
  # env vars and -D system properties. bootstrap.properties is never read, so the key must go here.
  set_prop "$cfg/application.properties" bootstrap.genesisPublicKey "$genesis_pub"
  sed -i '/^[[:space:]]*bootstrap\.genesisPublicKey[[:space:]]*=/d' "$cfg/bootstrap.properties"
  if [[ -n $ledger_id ]]; then
    set_prop "$cfg/application.properties" ledger.id "$ledger_id"
    set_prop "$cfg/bootstrap.properties" ledger.id "$ledger_id"
  fi
  if [[ -n $chain_id ]]; then
    set_prop "$cfg/application.properties" contracts.chainId "$chain_id"
    set_prop "$cfg/bootstrap.properties" contracts.chainId "$chain_id"
  fi
  if [[ -n $grpc_port ]]; then
    set_prop "$cfg/node.properties" grpc.port "$grpc_port"
    set_prop "$cfg/node.properties" grpc.tlsPort "$(( grpc_port + 1 ))"
  fi
  own_by_hedera "$HAPI_DIR"

  grep -q "^bootstrap.genesisPublicKey=$genesis_pub\$" "$cfg/application.properties" || \
    die "genesis key was not written to $cfg/application.properties"
  log "Genesis key set in data/config/application.properties (the file the node reads at genesis)"
  log "Network-wide file fingerprints (must match on every node):"
  (cd "$HAPI_DIR" && sha256sum settings.txt data/config/{genesis-network.json,application.properties,bootstrap.properties,api-permission.properties})
}

# service <nodeId> [--heap-min 8g] [--heap-max 16g] [--no-start]
cmd_service() {
  need_root service
  load_node_env
  local id="" xms=8g xmx=16g start=1
  while [[ $# -gt 0 ]]; do
    case $1 in
      --node-id) id=$2; shift 2 ;;
      --heap-min) xms=$2; shift 2 ;;
      --heap-max) xmx=$2; shift 2 ;;
      --no-start) start=0; shift ;;
      -*) die "unknown option $1" ;;
      *) id=$1; shift ;;
    esac
  done
  [[ -n $id ]] || id=$NODE_ID
  [[ -n $id ]] || die "no node id: run gen-keys first, or pass --node-id <id>"
  if [[ -n $NODE_ID && $id != "$NODE_ID" ]]; then
    die "--node-id $id does not match this host's keys (node id $NODE_ID in $(NODE_ENV_FILE))"
  fi
  local name; name=$(node_name "$id")
  [[ -f "$HAPI_DIR/data/keys/s-private-$name.pem" ]] || die "missing data/keys/s-private-$name.pem (node id $id -> $name)"
  [[ -f "$HAPI_DIR/data/config/genesis-network.json" ]] || die "run configure first"
  [[ -f "$HAPI_DIR/data/apps/HederaNode.jar" ]] || die "run install first"
  local java_bin; java_bin=$(command -v java) || die "java not found"

  cat > /etc/systemd/system/hiero-node.service <<EOF
[Unit]
Description=Hiero consensus node (id $id / $name)
After=network-online.target
Wants=network-online.target

[Service]
User=$HEDERA_USER
Group=$HEDERA_USER
WorkingDirectory=$HAPI_DIR
ExecStart=$java_bin --enable-native-access=ALL-UNNAMED --sun-misc-unsafe-memory-access=allow \\
  -Xms$xms -Xmx$xmx -XX:+UseZGC \\
  -cp "data/lib/*:data/apps/*" com.hedera.node.app.ServicesMain -local $id
Restart=on-failure
RestartSec=10
LimitNOFILE=1048576
StandardOutput=append:$HAPI_DIR/output/stdout.log
StandardError=append:$HAPI_DIR/output/stdout.log

[Install]
WantedBy=multi-user.target
EOF
  systemctl daemon-reload
  systemctl enable hiero-node.service
  if (( start )); then
    systemctl restart hiero-node.service
    log "Started. Nodes wait in STARTING_UP/OBSERVING until >2/3 of weight is online."
  fi
}

# allow-mirror --pubkey "<ssh public key>" [--from <mirror ip>]
# Lets a mirror node pull this node's record streams: a dedicated user whose only possible action
# is a read-only rsync of /opt/hgcapp/recordStreams (rrsync forced command, no shell, no forwarding).
cmd_allow_mirror() {
  need_root allow-mirror
  local pubkey="" from="" user="${STREAMS_USER:-hiero-streams}"
  while [[ $# -gt 0 ]]; do
    case $1 in
      --pubkey) pubkey=$2; shift 2 ;;
      --from) from=$2; shift 2 ;;
      *) die "unknown option $1" ;;
    esac
  done
  [[ $pubkey =~ ^ssh-(ed25519|rsa)\ [A-Za-z0-9+/=]+ ]] || die "usage: allow-mirror --pubkey \"ssh-ed25519 AAAA...\" [--from <mirror-ip>]"
  [[ -x /usr/bin/rrsync ]] || { apt-get install -y -qq rsync >/dev/null; [[ -x /usr/bin/rrsync ]] || die "rrsync not found (rsync package)"; }
  local streams=/opt/hgcapp/recordStreams

# The sync loop: one rsync per node per pass, read-only rrsync on the node side.
cmd_sync_once() {
  local key; key=$(KEY_FILE)
  [[ -f $key && -f $(NODES_FILE) ]] || die "run prepare-host and configure first"
  local acct ip ok=0 total=0
  while read -r acct ip; do
    [[ -n $acct ]] || continue
    total=$((total + 1))
    mkdir -p "$(STREAM_DIR)/record$acct"
    # remote path is relative to /opt/hgcapp/recordStreams (enforced by rrsync on the node)
    if rsync -a --chown="$CONTAINER_UID:$CONTAINER_UID" --timeout=20 \
         -e "ssh -i $key -o BatchMode=yes -o StrictHostKeyChecking=accept-new -o UserKnownHostsFile=$MIRROR_DIR/keys/known_hosts -o ConnectTimeout=5" \
         "$STREAMS_USER@$ip:record$acct/" "$(STREAM_DIR)/record$acct/" </dev/null; then
      ok=$((ok + 1))
    else
      warn "sync from $acct ($ip) failed"
    fi
  done < "$(NODES_FILE)"
  echo "$ok/$total"
}

cmd_sync_loop() {
  need_root sync-loop
  while :; do
    cmd_sync_once >/dev/null || true
    sleep "$SYNC_INTERVAL"
  done
}

Gaps found in NMT v1.3.8
  • No public installation guide.
  • Prerequisites are not installed. Docker buildx is not checked, and its absence causes a misleading "Image Not Found After Build" error.
  • The JVM is sized for mainnet hardware.
  • No health check: the container shows "Up" whether or not the node is in consensus.
  • The node container's restart policy is "no".
  • stop kills the node instead of shutting it down cleanly.
  • Event streams stay on, which caused the disk exhaustion described in section 2.
